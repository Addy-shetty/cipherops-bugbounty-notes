# Link Extraction Tools

Tools for pulling endpoints, URLs, and links out of JavaScript files and web responses:

1. [LinkFinder](https://github.com/GerbenJavado/LinkFinder) — a Python script that finds endpoints in JavaScript files.
2. [JS-Scan](https://github.com/zseano/JS-Scan) — a JavaScript scanner built in PHP, designed to scrape URLs and other information.
3. [LinksDumper](https://github.com/arbazkiraak/LinksDumper) — extracts links or possible endpoints from responses and filters them via decoding/sorting.
4. [GoLinkFinder](https://github.com/0xsha/GoLinkFinder) — a fast, minimal JS endpoint extractor written in Go.
5. [BurpJSLinkFinder](https://github.com/InitRoot/BurpJSLinkFinder) — a Burp extension for passive scanning of JS files to find endpoint links.
6. [urlgrab](https://github.com/IAmStoxe/urlgrab) — a Go utility to spider a website searching for additional links.
7. [waybackurls](https://github.com/tomnomnom/waybackurls) — fetches all URLs the Wayback Machine knows about for a domain.
8. [gau](https://github.com/lc/gau) — fetches known URLs from AlienVault OTX, the Wayback Machine, and Common Crawl.
9. [getJS](https://github.com/003random/getJS) — quickly retrieves all JavaScript sources/files.
10. [linx](https://github.com/riza/linx) — reveals invisible links within JavaScript files.
