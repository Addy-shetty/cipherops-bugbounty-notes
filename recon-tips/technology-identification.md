# Technology Identification

Tools for identifying the technologies, frameworks, and libraries running on a target website:

1. [Wappalyzer](https://github.com/AliasIO/wappalyzer) — identifies technologies used on websites.
2. [Webanalyze](https://github.com/rverton/webanalyze) — a port of Wappalyzer that automates mass scanning to uncover technologies in use.
3. [Python-builtwith](https://github.com/claymation/python-builtwith) — a client for the BuiltWith API, for retrieving technology information about websites.
4. [WhatWeb](https://github.com/urbanadventurer/whatweb) — a next-generation web scanner that identifies technologies and gathers information about websites.
5. [Retire.js](https://github.com/RetireJS/retire.js) — detects the use of JavaScript libraries with known vulnerabilities.
6. [httpx](https://github.com/projectdiscovery/httpx) — a fast, versatile HTTP toolkit that runs multiple probers using the retryablehttp library, built to stay reliable at high thread counts.
7. [Fingerprintx](https://github.com/praetorian-inc/fingerprintx) — a standalone utility for service discovery on open ports; works well alongside other bug bounty command-line tools.
